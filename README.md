## 📖 О проекте

**Extra Hands** — набор ботов для оптимизации рутинных действий в GTA5RP. 

---

## ✨ Особенности и возможности

-   **Гибкий интерфейс**: Каждый бот настраивается под желаемые требования.
-   **Имитация человека**: Между любыми дейсвиями есть рандомная пауза, чтобы не вызывать подозрений системы.
-   **Сохранение настроек**: Все параметры ботов и видимость модулей в меню сохраняются в файле `settings.json`.

---

## 📦 Установка необходимых библиотек

Перед запуском исходного кода убедитесь, что у вас установлены все необходимые библиотеки. Выполните команду в терминале:

```bash
pip install PyQt5 opencv-python numpy pyautogui keyboard pynput mss pillow pyinstaller
```

## 🧩 Список доступных ботов

Ниже представлены все модули, входящие в состав Extra Hands:

### 🎮 AFK+

-    Описание: Предотвращает автоматический выход из игры (Anti-AFK) путем случайных нажатий клавиш (W, A, S, D).
  
-    Настройка: Включение/отключение быстрого зажатия клавиш.
 
### 🎡 Колесо удачи

-    Описание: Автоматически выполняет прокрутку "Колеса Удачи".

-    Настройка: Установка начальной задержки (часы/минуты) перед первым запуском. Дальше цикл повторяется каждые 4 часа 10 минут.

### 👨‍🍳 Готовка

-    Описание: Макрос для автоматизации процесса крафта. Пользователь записывает последовательность кликов по ячейкам, и бот ее повторяет заданное количество циклов.

-    Настройка: Запись последовательности (инструменты, ячейки), количество циклов.

### 💪 Тренажерный зал (Gym)

-    Описание: Продвинутый бот для тренировок. Отслеживает две окружности (белую и зеленую) и нажимает пробел в нужный момент. Поддерживает случайные промахи.

-    Настройка: Количество подходов, клавиша с едой, режим "Эспандер" и клавиша с эспандером.

### 🏗️ Стройка

-    Описание: Бот для строительства. Отслеживает зеленый цвет (маркер) и определяет, какую клавишу (E, F или H) нужно нажать, используя сравнение с шаблонами изображений.

-    Настройка: Задержка между нажатиями.

### ⚓ Порт

-    Описание: Нажимает клавишу E при обнаружении зеленого цвета. Имеет встроенную функцию "Автобег" (зажимает Shift + W) по нажатию F7/F8.

-    Настройка: Включение автобега, глобальные горячие клавиши.

### ⛏️ Шахта

-    Описание: Простой и эффективный бот. При обнаружении зеленого цвета начинает многократно нажимать клавишу E.

-    Настройка: Задержка между нажатиями.

### 🐄 Ферма (коровник)

-    Описание: Бот для автоматизации доения коров. Анализирует цветовые маркеры для нажатия клавиш A или D. Также отслеживает "опасный" красный цвет и делает паузу до его исчезновения.

-    Настройка: Задержка между нажатиями.

### 🔧 Токарь

-    Описание: Автоматически перемещает курсор мыши на изображение стамески (chisel.png). Использует сопоставление с шаблоном для точного позиционирования с возможностью смещения.
